# Android 0.1.34 预览版

三项更新:

- **回测分析加深**:
  - **仓位比例**:每次进场可只用空仓现金的 10%–100%(默认 100%);仍是一次买够,不是加减仓。
  - **月度收益表**:逐月的策略收益与买入持有对照(月初基准是上月最后一天的权益)。
  - **最深的 3 段回撤**:前高 → 谷底 → 恢复的日期、深度和耗时,没恢复的写「到最后还没恢复」。
  - **样本内 / 样本外对照**(单只股票):前 70% 里跑固定小格参数、按收益选最好的,再看它在后 30%(没参与选择)的表现,并给出它在样本外的排名、全部参数样本外收益的中位数和为正的比例。样本外排名靠后或收益为负,说明那一格只是拟合了过去。只切了一段样本外,不是严格的滚动检验;K 线太短时明说不够切。
  - **回测结果分享图**:图上标「回测结果(历史假设)」,只含这次回测的设定和读数,不含自选与持仓。
- **更多页面可「问 AI」**:盘面事实、涨停全表两页也登记了读数并带按钮(规则同 0.1.32:勾选「附带当前页面」才发送、只用于这一问、不进对话历史;取不到的块写原因)。
- 回测页其余口径不变:默认计费用、100 股整手、涨跌停按板块近似、没有停牌模拟,结果只是历史假设核对。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
