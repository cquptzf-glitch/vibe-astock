# Android 0.1.31 预览版

**回测页大升级**(Lite 回测,日线、前复权):

- **交易成本**:默认计入佣金(万 2.5、最低 5 元)、过户费和卖出印花税;可改成「不计费用」;滑点可填(bp,默认 0,不替你假设);结果里单列总费用和滑点成本。默认费率只是初值,不是你的真实费率,页面和说明里都写明。
- **A 股整手**:按 100 股整手买入,钱不够一手就不买(记为「因资金不足跳过」),不再有零碎股数。
- **三种策略**:均线交叉、通道突破(收盘突破前 N 日最高收盘进场、跌破前 M 日最低收盘出场)、RSI 超卖反弹(Wilder RSI);都是「前一交易日收盘出信号,下一交易日开盘成交」。可选**止损**(收盘跌到成本价下方 N% 后下一开盘卖出)。
- **多标的组合**:最多 5 只,等权、各自独立(本金平均分、不再平衡,日期取各只共有的交易日),给组合权益曲线和分标的结果。
- **参数实验**:单只股票可同时跑一小格固定参数组合(均线 3×3、通道 3×3、RSI 买卖线 3×3),看参数一动结果怎么变、有多少组是正收益。**这不是自动寻优**,挑最好一格当结论就是过拟合;K 线根数不够跑的格子直接略过,不硬凑。
- **更多读数**:年化收益、日度夏普、胜率、成交明细(最近 20 笔,含卖出原因:信号 / 止损)。

仍然偏乐观、没有模拟的:涨停买不进、跌停卖不出、停牌、除手续费外的其它限制。结果只是历史假设核对,不是买卖建议。
