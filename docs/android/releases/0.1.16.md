# Android 0.1.16 预览版

本轮新增四项能力：

- 个股资金流：20/60/120 日净额、分钟当日累计、各档金额、最近记录与缺值提示。
- 异常监控：来源异常偏离名单分页、当前页筛选、重点监控生效窗口，点击进入股票。
- 所属板块：从股票反查板块，再进入板块详情/成分股；支持多级返回。
- 量价观察：完整窗口的均线/涨跌、MA5/20 交叉、此前20根区间与前5根均量对比，全部由 Rust 计算。

同步加强东财 K 线身份、日期、OHLC 与成交量校验，补公开冻结样本和移动呈现回归测试。

这是 debug-signed ARM64 预览 APK，供功能验收；正式签名/AAB 与设备生命周期验收尚未完成。不同 CI 的默认调试签名可能变化，不能保证覆盖安装，更换安装前请先导出业务备份。APK 与 SHA256 均附于本次 Release。

尚未实现：Kalshi 远期、完整盘中异动/批量扫描、历史估值、AI 流式/多会话/工具/深度研究、完整回测、成熟候选/自动事件日历、交易复盘与内容库深化、图片/文件分享、加密备份、持续后台盯盘、统一缓存限流、正式签名/AAB及系统真机验收。详见仓库 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。

所有读数仅记录来源数据和已发生的市场现象。分钟资金流是当日累计，不能逐分钟相加；个股日线可能尚未收盘，不提供买卖建议。
