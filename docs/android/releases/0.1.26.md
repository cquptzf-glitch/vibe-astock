# Android 0.1.26 预览版

- **自选 / 持仓「从截图识别」(AI 多模态)**:在 AI 模型设置里,新增「常用厂商」选型(选一个自动填 Base URL 和默认模型名:DeepSeek、智谱 GLM、Kimi、小米 MiMo、OpenAI、通义千问、自托管)、「支持图片识别」开关和「测试图片识别」按钮(用本机画的一张小图问模型,读出代码才算通过并自动打开开关;同一厂商的不同模型差别很大,是不是多模态以厂商文档为准)。打开后,自选页和持仓页多了「从截图识别」:选 1–4 张证券 App 截图 → 模型读出代码、名称(持仓还有数量、成本)→ 代码与名称再用腾讯股票搜索核对一遍(对不上的标出来,只有名称的给候选、不替你选)→ 逐条对照截图核对(可以改),勾选后才写入自选,或记成一笔期初买入(建仓日期由你填,成本按截图,费用记 0;已有持仓的代码不让叠加)。读不到的项是空的,不当 0。截图在手机上缩小后发给你配置的模型,不保存。
- **可选加密备份**:设置页「备份口令」填了就加密导出(PBKDF2-SHA256 31 万次 + AES-256-GCM,口令至少 8 个字符,不保存、不上传,忘了就解不开);恢复时自动识别加密备份并要口令,口令错或文件被改说同一句话。不填口令仍是原来的明文 JSON 备份。
- **统一清除全部本地数据**:设置页新增一键清空——自选、交易日志与成交、分红、日复盘、AI 聊天与模型配置、资料库、日历、提醒、所有行情缓存,以及 Android Keystore 里的 API Key,并取消已排的提醒;两次确认,清完重新加载。建议先导出备份。
- **消息(「我的」→「消息」)**:盘前提醒(交易日 09:30 前,用上一交易日的情绪读数)、收盘摘要(最近一个已收盘交易日的涨停 / 炸板 / 跌停 / 最高板 / 炸板率、昨日涨停股今日表现、整体晋级率,再加自选里涨跌幅 ≥ 5% 或触及涨跌停的)、自选异动(盘中每次打开时取一次行情,覆盖成最新一份)。**没有后台推送**:只在打开 App 或点「刷新」时按当天行情生成,没开 App 的时候不会有消息;「我的」导航上有未读角标。内容只列已经发生的读数,不含持仓与盈亏,不构成买卖建议;消息不进备份,可以随时清空。
- 数据库升级到 v10(模型配置新增「支持图片识别」开关、新增消息表;已装版本打开会自动升级,备份格式不变)。

识别结果依赖你自己配置的模型,可能读错数字或名称,所以一律要逐条核对才写入。这版没有在真机上、用真实模型跑过;Keystore 清除与提醒取消走原生命令层,同样未在真机验证。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
