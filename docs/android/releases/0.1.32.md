# Android 0.1.32 预览版

四项更新:

- **问 AI(附带当前页面)**:今日情绪、首板名单页上多了「问 AI」按钮,点了跳到 AI 对话,预填问题并**默认勾选「附带当前页面」**(只是勾选,不会自动发送,你可以改问题或取消勾选)。勾选后,这一页上显示的读数(今日情绪的赚钱效应/晋级率/连板溢价/梯队;首板名单逐只一行,含首封时间、炸板、涨停原因)随这一问发给你配置的模型,**只用于这一问,不存进对话历史**,回复后会写明附带了哪一页。取不到的读数写原因、不写 0;涨停原因没覆盖的票会叮嘱模型不要凭印象补。**交易日志各页、我的持仓、盯盘/竞价等含个人成交持仓的页面不登记,进入这些页面还会清掉上一页留下的登记**——个人成交、持仓、盈亏不进 AI 的规矩不变。
- **回测模拟涨跌停**:按板块幅度近似(主板 10%、创业板/科创板 20%、北交所 30%):开盘价贴着涨停价买不进、贴着跌停价卖不出,信号留到下一根再试,结果里统计「涨跌停没成交」的次数;可在回测页关闭。ST 股(5%)和新股上市初期不设限这两种没单独识别,停牌没模拟,结果仍可能偏乐观。
- **取数统一重试与并发上限**:所有走统一取数入口的行情/资讯请求,遇到网络错误、超时、429、5xx 会退避重试最多 2 次(300ms、600ms),4xx 不重试;同时在途请求上限 8 个,详情页一次发很多路请求时不再把网络压满。失败信息仍带 HTTP 状态码。
- **页面按需加载(路由分包)**:除首页、个股、盯盘等常用页外,其余页面第一次进入时才加载,主程序包从 461 kB 降到 183 kB(压缩后 133 → 57 kB),启动解析更快。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
