# Android 0.1.33 预览版

三项更新:

- **候选池深化**:条件组合方式可选「满足全部 / 满足任一」;新增「涨跌幅」条件(共 6 项);**条件改动立即重新判断,不用重新取行情**;结果可按满足条件数、涨跌幅、PE、PB、总市值、成交额、换手率、名称排序(空值永远排在最后);自选池可按**自选分组**过滤;可把当前条件**保存成命名组合**(最多 10 组,存在本机浏览器里,不进备份),一键套用或删除。取不到的读数仍然单独列在「待补数据」,不当成「不符合」,也不当成 0。
- **更多页面可「问 AI」**:连板天梯、行业题材、近 5 天、情绪历史四页也登记了页面读数并带「问 AI」按钮(规则同 0.1.32:只有你在 AI 对话里勾选「附带当前页面」才发送、只用于这一问、不进对话历史)。近 5 天页的按钮会让模型按这页近 5 个交易日写一份**市场周报**;页面上下文里**不含「我的交易」**,提示词也要求不提个人交易。
- **连板天梯分享图**:连板天梯页多了「图片分享卡」,画 2 板以上的层(高板在前,最多 6 层)和涨停 / 最高板汇总,右侧文字过长自动缩小字号;只含市场读数、不含自选与持仓、不给买卖建议。分享走 0.1.27 的原生分享(未在真机验证)。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
