# Android 0.1.19 预览版

按桌面版左侧栏重新组织移动端，并迁移情绪复盘的「今日情绪」整套读数：

- 底部五个一级栏目对应桌面版：首页 / 盯盘 / 复盘 / 研究 / 我的；每个栏目顶部有横向子页签，同组功能一屏可见，右侧进入「全部功能」目录（可搜索）。
- 复盘栏目新增：今日情绪、连板天梯、涨停全表（涨停/炸板/跌停三池）、首板名单、盘面事实、行业题材，与每日复盘、交易日志、交易统计放在一起；复盘日可选历史交易日、最近收盘或今日盘中。
- 今日情绪：赚钱效应（中位/均值/翻红率/再度涨停）、晋级率（1进2/2进3/3板以上）、连板溢价、梯队断层、情绪周期（近 10 个交易日相对分、距低点第 N 天与最近走向）、封板质量，并与前一交易日对照。
- 连板天梯：每层的晋级 base/promoted、没接上的票按跌停/炸板/没涨停/没取到标注，反包写成「N天M板」。
- 盘面事实：昨日强势股反馈矩阵与逐只明细、亏钱效应、封板质量（炸板率口径写明）、10cm/20cm/北交所/ST 分制度生态。
- 行业题材：行业梯队、首封→末封发酵节奏、昨日→今日延续率、退潮行业、涨停时间分布，以及关键事件账本（钱亏在哪/分歧最大/钱赚在哪）。
- 首页增加情绪速览（最近收盘日的涨停、炸板率、跌停、最高板、1进2、赚钱效应）和按工作流排列的 8 个入口。
- 资料库拆成研究记录、我的研报、收件箱三页，支持正文/代码检索、分类筛选、未读筛选与全文展开。
- 读数全部由 Rust Core 用东财公开池子计算，取不到的写明原因、显示为 —，不补 0；只描述已发生的盘面现象，不给买卖建议。

口径差异：题材按东财所属行业归，桌面版另用同花顺涨停原因；亏钱效应与反馈矩阵只用定稿记录，不含昨日炸板股。

APK 为 debug-signed ARM64 预览版。正式签名/AAB、真机生命周期及覆盖升级仍需验收，更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
