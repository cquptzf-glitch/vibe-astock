# Android 0.1.18 预览版

在紧凑工作台与白色模式的基础上，进一步压紧窄屏个股详情：

- 顶部常驻“设置”和主题切换，支持白色/深色/跟随系统。
- 设置页直接配置外观、紧凑/舒适密度、30/60/120 秒或手动刷新，并可展开模型 API 配置，管理通知与备份。
- 首页展示 6 个指数、沪深北成交额、涨跌宽度与分布、短线情绪、8 个功能入口、自选价格/涨跌/成交额。
- 个股研究、量价/资金/板块标签保持单行，技术指标改为紧凑三列，减少留白与阴影；红涨绿跌在两种主题中保持清晰。
- 个股取 100 根日线计算完整 60 根涨跌窗口，缩略图仍展示最近 60 根；历史不足留空，缺失成交额不显示为零。
- CI 在 360/390/768 像素、白色/深色下检查主题切换/保存/系统跟随、密度、设置表单、单行标签、三列指标及横向溢出，生成 18 张冻结测试数据截图。

APK 为 debug-signed ARM64 预览版。正式签名/AAB、真机生命周期及覆盖升级仍需验收，更换安装前请导出业务备份。

本版未宣称所有剩余业务已迁移。Kalshi 远期、完整盘中扫描、历史估值、AI 流式/多会话/工具/深研、完整回测、候选/日历及交易内容库深化、图片/文件分享、加密备份、持续后台盯盘、统一缓存离线等仍见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
