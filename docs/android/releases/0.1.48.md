# Android 0.1.48 并行预览与月营收图表

**本版为新的并行预览应用 `com.vibeastock.preview`，桌面名称为 Vibe AStock Preview。它与旧版 `com.vibeastock.mobile` 并存，不覆盖旧应用，也不会自动读取旧应用数据。** 原预览签名私钥已无备份、CI 缓存为空，维护者已明确选择新包名并行安装。需要迁移时，先在旧应用导出业务备份，再在新应用导入；两版 SQLite v13 / 业务备份 v11 一致。旧 APK 和原签名记录保留。

新预览签名已独立固定，私钥通过 GitHub Actions 加密 Secret 恢复，不再依赖缓存；证书与包名都需核对后才能发布。Secret 损坏、错误证书、错误包名或缺失私钥会拒绝发布，不能自动生成替代升级身份。原生外部链接入口按当前 applicationId 绑定，避免新包仍指向旧包 Activity。正式分发默认包名与原签名记录保持原状。

台系供应链月营收新增 SVG 走势图，支持近 12 月、近 24 月和完整区间。缺月断线、不补零；不足两个月不画图。完整历史表保留，金额单位为亿新台币。当前图表可生成并分享真实 PNG，保留公司、区间、来源、缺月、滞后及资料边界；区间或元数据变化后旧预览失效。没有扩充原有四家公司的自动取数覆盖，不由图表推断 A 股公司业绩。

Actions 无法触发的根因已查明：fork 的工作流被单独禁用，普通权限 API 的 enabled=true 未反映这一状态。通过仓库 Actions 页恢复后，0.1.47 工作流已实际运行，Rust、前端和手机页面验证通过，但因旧签名缓存为空停在签名检查。本版补齐新的并行发行链路；诊断经过见 [Actions 故障记录](../actions-troubleshooting.md)。

本地：前端 585 项通过，桌面与移动构建通过；47 路由的 166 组页面/状态检查通过；新增月营收图表四尺寸明暗主题 8 组检查、8 张真实导出 PNG，通过区间切换、缺月断线、完整表格和分享字节一致性检查。发行辅助脚本 12 项通过，真实新密钥恢复后与固定证书一致；新包 Android 工程生成通过。Rust Core 严格 Clippy 与 Core/Tauri 格式检查通过。本机 Gradle 原生测试遇到 loopback 连接失败，Android APK/AAB 与原生测试以 CI 回执为准；没有真机验收。

交易数据与模型处理保持原状。新包的自定义 scheme 与旧包相同，系统打开外部链接时可能要求选择应用；通知由各应用自己的包处理。真实设备上的后台、通知、分享、导入及两包并存仍需设备验证。
