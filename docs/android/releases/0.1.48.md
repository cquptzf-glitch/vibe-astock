台系供应链月营收新增 SVG 走势图，支持近 12 月、近 24 月和完整区间。缺月断线、不补零；不足两个月不画图。完整历史表保留，金额单位为亿新台币。当前图表可生成并分享真实 PNG，保留公司、区间、来源、缺月、滞后及资料边界；区间或元数据变化后旧预览失效。没有扩充原有四家公司的自动取数覆盖，不由图表推断 A 股公司业绩。

Actions 无法触发的根因已查明：fork 的工作流被单独禁用，普通权限 API 的 enabled=true 未反映这一状态。通过仓库 Actions 页恢复后，0.1.47 工作流已实际运行，Rust、前端和手机页面验证通过，但因旧签名缓存为空停在签名检查。本版补齐新的并行发行链路；诊断经过见 [Actions 故障记录](../actions-troubleshooting.md)。
