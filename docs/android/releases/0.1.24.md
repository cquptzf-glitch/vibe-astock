# Android 0.1.24 预览版

界面整体改版,加上「我的股票」的一批功能:

**界面**

- **去掉顶部软件信息栏**:页面从屏幕顶端开始,多出约 70px 的内容空间(状态栏区域用安全区留白)。
- **底部菜单新增「设置」**:现在是「首页 / 盯盘 / 复盘 / 研究 / 我的 / 设置」六项。主题模式(白色 / 深色 / 跟随系统)、信息密度、刷新频率都在设置页里;原来顶部的主题切换按钮随顶栏一并移除。版本号与核心状态在设置页的「Rust Core」格里。
- **信息更紧凑**:紧凑密度下收紧页面边距、卡片内边距、读数格(3 / 4 列并排)、子页签、按钮与输入框高度;各页标题块只留页面名,说明文字不再占行。复盘「今日情绪」页在 360px 宽下由约 2110px 缩到约 1600px。「舒适」密度保持原来的宽松间距。
- **控件改成网页自绘**:下拉(底部弹出的选项列表)、日期选择(自绘月历,周一开头,可翻月 / 翻年、点「今天」)、复选框、确认与提示对话框,全部用页面元素画,跟随明暗主题,不再弹出 Android 系统自带控件。系统文件选择器无法替代,仍用系统的(导入备份、导入表格时)。

**我的自选**(盯盘 → 我的自选)

- 每只多了市盈率(TTM)、市净率、换手率;亏损显示「亏损」(市盈率为负)或「净资产为负」,排序时和没有数据一起排最后。
- 可按涨跌幅 / 成交额 / 换手率 / 市盈率 / 市净率 / 现价 / 名称排序,可切换高→低或低→高,也可用「自定义顺序」逐只上移下移(选了分组时只在该分组内调整,不影响其它分组里的相对顺序)。
- 给每只写分组(最多 12 字)和标签(最多 5 个、每个 8 字),按分组筛选;超长或带逗号直接拒收,不截断。直接输入代码就能添加。持仓里的票带「持仓」标记。
- 分组、标签、自定义顺序存在本机、进备份;旧备份恢复后为空分组、无标签、没有自定义顺序。

**我的持仓**(盯盘 → 我的持仓)

- 新增「已实现与分红」:已实现盈亏沿用「交易统计」口径——清仓后才计入(净额),在手的票另列持有数量与成本;现金分红是手填的收入,单独列、不并进已实现盈亏、不改持仓成本;在手 / 已清仓或只有分红的票分开列,分红可记、改、删(日期不能是未来,同代码同日同金额不重复)。
- 个人持仓、盈亏与分红只在本机、进备份,不进任何 AI。

**交易日志 · 从表格导入成交与分红**

- 粘贴券商导出的表格(CSV 或从表格软件复制)或选文件(UTF-8 / GBK 都能读)→ 逐行预览(可导入 / 已记过 / 有问题及原因)→ 导入。按日期重放切成「一轮一轮」的交易,同一天先算买入再算卖出;1–5 位纯数字代码、负数数量、未来日期、卖出超过此前买入等都拒收并写原因;与已记成交完全相同的行标「已记过」不重复导入;期初持仓、送转拆股行暂不支持(写明原因)。导入是一个事务,导入后可一键撤销这批交易记录。全部在本机处理。

数据与存储:本地数据库升级到 v8,备份格式升到 v8(v1–v7 备份仍可恢复)。v8 新增自选的分组 / 标签 / 顺序三列和 `mobile_dividends`(分红)。

未做:收益表现、持仓体检、历史回放、截图导入、自选批量按名称添加(目前按代码添加)仍在清单里。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
