# Android 0.1.24 预览版

界面整体改版,不改业务数据口径:

- **去掉顶部软件信息栏**:页面从屏幕顶端开始,多出约 70px 的内容空间(状态栏区域用安全区留白)。
- **底部菜单新增「设置」**:现在是「首页 / 盯盘 / 复盘 / 研究 / 我的 / 设置」六项。主题模式(白色 / 深色 / 跟随系统)、信息密度、刷新频率都在设置页里;原来顶部的主题切换按钮随顶栏一并移除。版本号与核心状态在设置页的「Rust Core」格里。
- **信息更紧凑**:紧凑密度下收紧页面边距、卡片内边距、读数格(3 / 4 列并排)、子页签、按钮与输入框高度;各页标题块只留页面名,说明文字不再占行。同屏能看到的内容约多 25%。「舒适」密度保持原来的宽松间距。
- **控件改成网页自绘**:下拉(底部弹出的选项列表)、日期选择(自绘月历,周一开头,可翻月 / 翻年、点「今天」)、复选框、确认与提示对话框,全部用页面元素画,跟随明暗主题,不再弹出 Android 系统自带控件。系统文件选择器无法替代,仍用系统的(导入备份、导入截图时)。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
