# Android 0.1.30 预览版

两项更新:

- **成本法可选先进先出**:「交易日志 → 风险与纪律 → 费率、规矩与账户规模」里多了「成本法」:移动加权平均(默认)或先进先出。先进先出时,卖出从最早买入的那一笔开始扣成本,买入费用跟着那一笔走;移动加权平均按卖出那一刻的均价扣。它只改已实现盈亏、分批卖出时的逐日盈亏和没清仓时的剩余成本,不改你记的成交;清仓后的总盈亏两种方法算出来一样。我的股票的持仓/已实现页、持仓分析、绩效等都跟着这个设置走。
- **自选批量按名称添加**:自选页的添加框现在可以代码和名称混着输(空格、逗号、顿号、分号分隔),比如「600519 平安银行」。名称走股票搜索:名称完全一致或只搜到一只就直接加;搜到多只又没有完全一致的,不会替你猜,会列出候选让你改用代码;没搜到的会写明,没加成的留在输入框里。

数据库升级到 v12(设置表多一列成本法;已装版本打开会自动升级),备份格式升到 v10(v1–v9 备份仍可恢复,恢复后成本法按移动加权平均)。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
