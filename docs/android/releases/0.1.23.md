# Android 0.1.23 预览版

交易日志分析页补全，加上复盘栏目的五块新读数：

- **交易日志（0.1.22 之后合并、本版首次发布）**：模式卡（版本化）、复查清单与最大浮盈浮亏（MFE/MAE，用户点「取行情并计算」才联网）、按入场环境分组（入场日情绪强中弱 + 当时板位）、看错还是没执行好（判断 × 执行四象限）、问题记录（算不进统计的记录可逐笔改正）。只有清仓后才计入已实现盈亏；只算 A 股股票，ETF / 可转债等只计入持仓。个人成交、持仓和金额只在本机，不进任何 AI，这些页面也不登记 AI 页面上下文。
- **复盘 · 题材事件树**：用同花顺涨停原因里的事件题材聚合（不是行业分类），每个题材列出昨日反馈、首封时间、扩散几只、梯队多高、炸了几个，并给出已发生读数推出的状态徽标。首板名单每只票带上涨停原因。题材归因来自源站编辑，不是公司确认；拿不到时整块标不可用，不退回行业分类冒充题材。
- **复盘 · 涨停分档**（市场面板里）：按行业题材看涨停分档，对比前两个交易日。
- **复盘 · 结构变化**：断点是市场变了、数据源变了还是规则变了——最近 10 个交易日 vs 之前 20 个交易日的涨停结构逐项比中位数；四张池子的上游字段清单有没有变；可以人工登记制度事件（系统不自动推断）。东财池子只留约一个月，本机缓存积累够天数前，市场结构比较会写明「暂不可用」及原因。
- **复盘 · 市场面板补沪深 300 估值**：沪深 300 市盈率、股息率（中证官网 xls，手机端现已能解析），与 10 年国债收益率一起给出股债利差；取不到时写明原因，不显示成 0。
- **复盘 · 昨日炸板股修复**（盘面事实页）：前一交易日炸板池里的票，复盘日当天均涨跌、翻红比例、再封板与跌超 5% 的只数，以及反馈矩阵里的「昨日炸板」一行与逐只明细。这些票不在东财「昨日涨停表现」定稿记录里，所以用前一交易日炸板池名单加实时行情算；行情快照不是复盘日（例如回看更早的日子）时整块标不可用并写明原因，盘中是此刻的读数。

数据与存储：本地数据库升级到 v7，备份格式升到 v7（v1–v6 备份仍可恢复）。新增表：模式卡与制度事件进备份；逐笔日线、入场环境池成员、同花顺涨停原因等公开行情缓存不进备份。已装 0.1.22 的设备打开新版会自动升级。

本版首次由 Agent 在「长期指示」下发布：未重做发布前隐私扫描。密钥 / 个人成交不入库、不进 AI、夹具只用公开行情或合成数据的约束仍然有效。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成，更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
