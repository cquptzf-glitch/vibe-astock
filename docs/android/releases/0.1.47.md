# Android 0.1.47 迁移后 Rust 工程收尾（本地候选）

清理 Rust Core 严格 Clippy 诊断，通过具名的回测配置、证据点与阶段输入整理过长参数；拆分复杂返回类型，减少大枚举占用，并修正规范写法。Core、Tauri 与本地插件完成 rustfmt 格式统一；未增加 lint 屏蔽。交易复查额外拒绝非有限成本，并覆盖 NaN、正负无穷、零和负数的回归。

Android 预览和正式分发工作流新增 rustfmt / 严格 Clippy 前置检查，显式安装对应组件。工作流 YAML 本地解析通过；平台执行结果需另行确认。

本地验证：Core 和 Tauri 的 `cargo fmt --all -- --check` 通过；Core `cargo clippy --locked --lib --tests -- -D warnings` 通过；Rust 单元测试 322 项通过、30 ignored，证券代码契约 1 项通过。重新执行的 9 个合成夹具生成测试通过；收益、体检、回放、风险、复查五组输出与 0.1.46 实际测试程序输出一致，仅排除风险设置的生成时间元数据。388 个计算冻结对照散列检查通过。

本轮未修改前端，界面与前端 584 项基线沿用 0.1.46；持仓四尺寸明暗主题的 24 张截图见本地 0.1.46 预览。SQLite v13 / 业务备份 v11 和交易数据与模型处理不变。源码版本 0.1.47，配置预期 versionCode 1047，不代表已生成或安装 APK。
