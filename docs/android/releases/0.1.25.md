# Android 0.1.25 预览版

「我的持仓」页补上三块分析,都只在点按钮时才联网取日线(结果在本次打开期间记 30 分钟):

- **收益表现**:时间加权收益(每天的涨跌连乘,看「选的票本身走得怎么样」,存取钱的多少和时机不影响它)、资金加权区间值与年化内部收益率(看「这些钱实际赚了多少」,区间不满一年不给年化)、逐只投入 / 取出 / 市值 / 盈亏、走势线。买入在当天开头投入、卖出与现金分红在当天收盘取出;没填费用的成交按设置里的费率估。价格用腾讯不复权日线;**手机端没有送转拆股流水**,价格出现单日断崖(收盘 < 前一天 72% 或 > 145%)时只列提醒,那一段的市值和时间加权收益可能算错;取不到价格的(北交所、持有超过约三年)整只不算、列进缺口。
- **持仓体检**:集中度(单只最大、前三、等效只数、最大行业,行业取东财所属行业,取不到的单列)、按现在的比例回看最近约一年的年化波动、最大回撤、历史 VaR95/99 与 CVaR、下行波动、每只的风险贡献、两两相关;可以自己设提醒线(单只占比、单个行业、年化波动、最大回撤,存在本机浏览器),超线才列出,不出综合分、不评好坏。共同交易日不足时把历史最短的那只移进缺口再算。
- **历史回放**:按现在的持仓比例,把 2015 年 6–8 月、2016 年初熔断、2018 年、2020 年 3 月、2021–2024 年五段大跌期重放一遍:组合涨跌、期间最大回撤、最差单日,和同期沪深 300 并排,再列每只的涨跌;当时还没上市或没有价格的进缺口、不当 0;有价格的不到一半市值就不给组合数字。只是回看,不是当时的真实持仓,不预测、不给操作提示。

范围:只做人民币 A 股与 ETF,没有港美股;收益表现与历史回放的取价、行业取数依赖腾讯 / 东财,上游取不到时会写明原因。个人持仓与收益只在本机,不进任何 AI。这三块的计算用合成价格序列测过,没有在真机上对真实上游点过,第一次用请留意缺口说明。

本版 CI 浏览器冒烟失败时会输出可匿名读取的 GitHub 注解,方便定位。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
