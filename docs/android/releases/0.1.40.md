# Android 0.1.40 手机布局预览（本地候选，尚无 APK）

让日常操作更适合手机屏幕：

- 底部收为首页、盯盘、复盘、研究、我的五栏；设置位于“我的”，保留返回入口。
- 复盘按市场、复盘记录、交易日志、交易分析分组；研究按个股和产业资讯分组。目录支持分类搜索，保留全部原有路由与 42 个功能入口。
- 首页先显示搜索、消息和常用操作，再显示市场详情。问 AI / 分享图使用页面内工具栏，避免盖住数据。
- 导航/搜索/筛选保留至少 44px 点击区域；320px 窄屏目录单列。交易日志补足边距，“记一笔”前置，成交表单按手机两列排列。

验证：前端 578 项、Rust 312＋1 项（28 ignored）、发行脚本 9 项、类型检查与桌面/移动构建通过。Edge 四尺寸 × 明暗主题共 320 张页面截图、24 张图表 PNG、40 张布局视口预览通过；所有数据为公开冻结/合成样本。

按维护者选择，本轮先交付本地预览，不等待 CI/APK。此前 GitHub 平台拒绝调度 Actions，本轮未再次请求调度或修改仓库权限；当前有发布回执的版本仍为 0.1.38。候选配置为 0.1.40 / versionCode 1040，不代表已构建 APK 或真机验收。SQLite v13 / 业务备份 v11、固定预览签名及交易数据与模型处理保持不变。

本轮未重跑未改动的编排器/Python 全套；上轮 Windows 契约仍有 5 项失败，Python 本机缺依赖，全量 fmt / 严格 Clippy 未通过仍保留。完整迁移与验收边界见 [当前清单](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
