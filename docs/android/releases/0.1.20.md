# Android 0.1.20 预览版

继续迁移桌面版情绪复盘，复盘栏目新增三个页签：

- **近 5 天**：每天涨停家数、最高板、炸板率、1进2 与当日最高标；行业轮动矩阵（每格为当天涨停家数，前三名高亮，取不到的日子显示 —、不当 0），状态写连续 N 天 / 隔 k 天回流 / 首次出现 / 今天退下去了；龙头谱系展示每天最高标自登顶以来的累计收益、最高到过多少、距高点回撤（前复权收盘价）。
- **情绪历史**：涨停家数、最高连板、1进2 晋级率、赚钱效应中位数、炸板率、跌超 5% 家数六项读数在近 10/20/30/60 个交易日里的分位；≥85% 或 ≤15% 分位标偏热/偏冷；与前一交易日比较只列超过噪声门槛的变化；逐日读数表把缺数的日子合并成一行说明。少于 10 天不给分位。
- **明日验证**：晚上从 8 个市场读数里选方向（上升 / 下降 / 持平）写下判断，下一场收盘后逐条对账，显示成立 / 不成立 / 判不了、方向的历史发生率与超额；下一场 09:15 开盘竞价后不能再写或改，之后写的标「事后」不计入战绩，未收盘的对账标「暂定」；累计战绩按近 60 个交易日汇总。只收市场层面读数，不涉及个股、点位或买卖。

数据与存储：

- 每天的读数由东财涨停 / 炸板 / 跌停 / 昨日涨停池与前一交易日涨停池在手机上计算。东财池子只留约一个月，已收盘且取全的日子存入本机 SQLite，历史会越用越长；更早又没缓存的日子如实显示没取到。
- 新增 SQLite schema v5（明日验证条件表、每日读数缓存表）；业务备份升级到 v5，包含明日验证条件（读数缓存是公开行情，不进备份）。旧版备份仍可恢复。

口径差异：行业按东财所属行业归（桌面版题材轮动用同花顺涨停原因）；头部行业集中度和全市场跌停也有历史序列，所以同样给基准发生率。

APK 为 debug-signed ARM64 预览版。正式签名/AAB、真机生命周期及覆盖升级仍需验收，更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
