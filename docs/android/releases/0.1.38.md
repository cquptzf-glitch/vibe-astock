# Android 0.1.38 预览版

修复预览版升级身份检查，并保留 0.1.37 的历史制度回测、产业资料库、送转 MFE/MAE 和后台官方月历。

- Gradle debug 签名显式使用缓存守卫校验过的密钥路径，避免默认目录解析选中另一个证书。
- 显式配置 Tauri Android 版本 0.1.38 / versionCode 1038，构建前核对 Cargo 版本；旧包内部仍为默认 1.0 / 1 的问题被修复。
- 发布前校验最终 ARM64 APK 的实际签名证书、包名、版本和 debug 属性；证书不匹配或签名失败时停止发布。公开回执同时保留预构建身份和最终包验证结果。
- 发行脚本增加错误证书、错误包名/版本/ABI、签名失败及配置幂等性回归，9 项通过；兼容 Build Tools 35/36 与 37 的签名输出格式。

0.1.37 及以前未建立同一可保证的预览签名身份，不能保证直接覆盖升级，迁移前请导出业务备份。预览仍是 debug-signed APK；正式发行密钥、商店、自有 App Links 域名和真机升级/后台行为尚未验收。SQLite v13 / 业务备份 v11 不变；交易数据与模型处理保持原状。

完整功能与边界见 [当前清单](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md) 和 [0.1.37 功能说明](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/docs/android/releases/0.1.37.md)。全量 Rust fmt / 严格 Clippy 仍需整理。
