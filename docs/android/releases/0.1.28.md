# Android 0.1.28 预览版

- **隐私模式**:在「设置 → 外观与显示 → 隐私模式」,或持仓页、交易日志页标题栏的眼睛按钮,一键开关。开着时:持仓、成交、成本、盈亏、分红、账户规模的**金额和股数遮成 ••••**(持仓页、已实现与分红、收益表现、持仓体检、交易日志记录与成交明细、风险与纪律、交易统计、入场环境、判断×执行、问题记录),价位 / 数量 / 费用 / 账户规模等输入框改成**密码样式**,**权益曲线不画**(曲线的高低起伏就是盈亏大小),持仓快照不能分享。市场行情、涨跌幅、收益率百分比、情绪读数不遮。开关存在本机,个人交易数据本来就不会发给 AI,隐私模式只管屏幕上看得见什么。

遮罩只管屏幕显示:截图、屏幕录制仍会拍到你没遮的内容;备份文件里的数据不受隐私模式影响(要保护备份请用设置里的加密导出)。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
