# Android 0.1.29 预览版

AI 对话三项升级:

- **流式输出**:回复一边生成一边显示(模型 API 要支持 `stream`,不支持的会自动按一次性回复读,一次给完)。
- **停止按钮**:生成过程中发送键变成「停止」,点了就中止这一轮——**取消的这一轮不保存**(包括你的那句提问,问题还留在输入框里)。
- **多会话**:AI 页顶部多了对话栏:切换对话、新对话、重命名、删除(默认对话不能删,只能清空);每个对话各自带上下文,互不串;新对话用第一个问题当标题;最多 50 个对话。对话和标题进备份(旧备份里的消息恢复后都归「默认对话」)。

聊天仍是独立聊天:不会自动附加自选、持仓、成交明细、交易备注或日复盘,个人交易数据不进 AI。流式事件走 Tauri 事件通道,**没有在真机上用真实模型验证**;请求形状、SSE 解析、停止与不保存用本地模拟服务测过。

数据库升级到 v11(新增对话表,消息表补 `thread_id`;已装版本打开会自动升级),备份格式升到 v9(v1–v8 备份仍可恢复)。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
