# Android 0.1.35 预览版

本轮补齐一批研究、回测、盯盘与资料功能：

- 六阶段研究/辩论/情绪复盘，市场周报、每日市场复盘与 20 赛道产业研究；支持暂停、继续、中止、证据与数字核对、独立版本归档。
- 完整财务三表/同比、汇总一致预期、历史 PE/PB 与分位；GPU 远期报价、台系供应链月营收、公告和事件概率。
- 自然语言回测、夏普区间、敏感度热图、滚动样本外、成本/指数对照、组合再平衡与加减仓、停牌日结转、历史规则覆盖。
- 全市场报价扫描和显式开启的 Android 后台盯盘，流量/电量停止线与常驻通知。
- 完整开休市月历、财报/公告同步与事件提醒；期初持仓、送转拆股和本周交易摘要。
- 受控聊天工具与可选资料检索；PDF/Word/Excel 本机解析预览、资料自动归档；公开页面浮动助手与分享图、公开数据离线缓存。
- 独立移动构建和自定义 scheme 外部深链。SQLite v13、备份 v11，升级前建议导出业务备份。

功能已落地不等于全部验收：逐笔行情、历史 ST/IPO 自动制度数据、桌面全量 calc/DAG 等价、真机后台/分享/备份恢复、正式签名/AAB 和 HTTPS App Links 仍未完成。Kalshi 在开发机网络中取数失败时会独立说明，不用现货或零替代。事件概率是有界扫描；图卡为文字摘要。具体边界、测试结果及发布回执见 [当前清单](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。

这是 debug-signed ARM64 预览版，正式渠道发布密钥与设备验收另行安排。
