# Android 0.1.21 预览版

个股页的 K 线与盘口按常用证券 App 的样子重做：

- **盘口**：现价、涨跌额、涨跌幅与行情时间；今开、昨收、最高、最低、成交量、成交额、换手率、振幅、量比、均价、涨停、跌停、市盈 TTM、市盈动、市净率、委比、总市值、流通值、外盘、内盘共 20 项；外盘/内盘比例条；可展开的买卖五档。非今日行情会标出。腾讯取不到时改用东财（东财快照没有五档，会说明）。
- **K 线**：分时、五日、日 K、周 K、月 K，以及 60 / 30 / 15 / 5 分钟；日、周、月可切换前复权 / 不复权。
- **主图**：蜡烛图 + MA5/10/20/60 或 BOLL(20,2)；可见区间最高、最低价标注；价格网格与时间轴。
- **副图**：成交量（含 5/10 均量）、MACD(12,26,9)、KDJ(9,3,3)、RSI(6,12,24)，公式与通达信 / 同花顺一致。
- **交互**：左右拖动看更早的 K 线，双指捏合、滚轮或 ± 按钮缩放（20~240 根），一键回到最新；点按或长按出十字线，信息条显示该根的时间、开高低收、涨幅、振幅、成交量、成交额、换手率，均线与副图数值同步跟随。
- **分时 / 五日**：价格线、均价线、昨收基线，左侧价格、右侧涨跌幅双轴，分时成交量柱（按涨跌着色），五日按天分隔；十字线显示每分钟价格、涨跌幅、均价与量额。盘中按设置里的前台刷新频率自动更新，后台暂停。
- 图表周期、指标与复权选择记在本机。

数据：K 线先取东财（含成交额、换手率），失败或被限流时改用腾讯（腾讯分钟 K 线不复权；北交所在腾讯只有很短历史，会提示）；分时与盘口先取腾讯，失败改用东财。异常 K 线（日期乱序、重复、最高价低于开收等）剔除并计数，不补值。指标只描述已经发生的价格，不构成买卖建议。

APK 为 debug-signed ARM64 预览版。正式签名/AAB、真机生命周期及覆盖升级仍需验收，更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
