# Android 0.1.49 手机功能布局与导航优化

参考 Apple Human Interface Guidelines 的导航、信息层级、分段选择与可访问性原则，完成手机端功能布局调整。底部保留首页、盯盘、复盘、研究、我的五个主要区域。原有 47 个路由保留，新增复盘工作台后共 48 个路由。

- **导航与返回**：会话内分别保留栏目的最近页面、筛选、表单和滚动位置；股票及板块详情沿用进入时的栏目高亮。切换栏目后，详情仍能通过页面返回和浏览器返回回到该栏目的父页面。全部功能目录不替换栏目最近工作页面，重新打开目录带入当前栏目并清除旧搜索。
- **页面状态与资源**：访问过的静态工作页面保留组件状态，股票/板块详情仅保留最近六个。隐藏页面从文档中脱离并暂停前台行情轮询、扫描和页面上下文登记；重新进入资料、持仓、交易统计等页面时刷新读数。状态保留限于当前应用会话，不承诺系统结束进程后恢复未保存表单。
- **入口分布**：盯盘使用自选、持仓、异动三个同级视图；竞价、异常监控仍可从目录进入。复盘工作台分为市场盘面、复盘记录、交易复盘三个分组，用列表进入具体功能。研究记录、研报、收件箱归入研究资料，原深链继续兼容。我的提供外观、模型、通知、备份四个直接入口，并定位到对应设置区域。
- **首页与工具**：首页前置搜索、主要指数和市场摘要，封板细分与涨跌分布可展开查看；日程、复盘及四个可编辑快捷入口随后展示。最近查看记录可清除。统一页头提供返回、当前标题和目录，通用 AI/文字分享收进“更多”，图表 PNG 导出保留在图表附近。
- **字号与交互**：增加 100%、125%、150%、200% 字号并在本机保存；页面字号改用相对单位，提高小字基线。设置和目录采用分组列表，大字号下自选排序和异动附加信息自动换行。弹出面板支持焦点约束、Escape、关闭后返回触发控件；键盘编辑时为内容让位，减弱动态效果偏好可关闭界面动画。

这是 Android/WebView 中对上述设计原则的实现，不代表 iOS 原生 Dynamic Type 或系统导航组件。手机键盘、系统返回、设备字体和后台行为仍需真机验收。交易数据与模型处理、SQLite v13、业务备份 v11 沿用现状。

继续使用并行包 `com.vibeastock.preview` 和 0.1.48 固定的新预览签名，与旧 `com.vibeastock.mobile` 并存。公开 APK 内部版本 0.1.49 / 1049 已独立核验，签名和 SHA256 与固定身份及公开校验文件一致。

验收范围与指南来源见 [手机布局验收表](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/docs/android/mobile-layout-audit-0.1.49.md)。本版 CI 增加栏目状态/返回/焦点/隐藏轮询交互检查，以及 320px 明暗主题的全部页面 200% 字号检查；已有逐页、图表分享与月营收检查继续执行。
