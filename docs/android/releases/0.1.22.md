# Android 0.1.22 预览版

盯盘与复盘补齐五块桌面版功能：

- **盯盘 · 实时动态**：盘中异动流（急拉 / 急跌：3 分钟内涨跌 ≥ 1.5%；封板 / 开板；同一只同一类 5 分钟内不重复，可按 1.5 / 3 / 5% 和「持仓与自选」筛选）；持仓、自选、昨日梯队（封住 / 上涨 / 下跌统计、按板位筛选）、500 亿以上大票涨幅前十与跌幅前五、昨日成交额前十。异动只在 App 开在前台的盯盘页或竞价页时判断，切到后台就停。持仓只显示现价、涨跌、浮动盈亏 % 和止损 / 目标状态，不显示股数和成本。
- **盯盘 · 竞价与盘中**：09:25 昨日涨停股竞价强弱（按开盘价）、分板位、最高标；09:25 / 09:35 / 10:00 / 11:30 / 14:00 / 15:00 六个时点的情绪路径；昨晚在「明日验证」写下的条件在各时点的盘中读数。时点快照只在窗口内（过时点 8 分钟内）且 App 开着盯盘页时存，补不回来；休市日不存。
- **复盘 · 涨停样本**：前一天涨停的票第二天收盘怎么样，按 7 种打法、首板最后封板时间、入场那天的情绪强弱分开看。样本是事后名单，不是策略回测，页面上始终带着这条说明。已收盘日子的明细存在本机，样本窗口会越用越长。
- **复盘 · 市场面板**：市场状态八格、主要指数中长线（5 / 20 / 60 / 250 日涨跌、年初至今、均线位置、离一年高点）、两市成交额与均值的比、两融余额、国债收益率、全球指数、行业资金、成交额前 20、龙虎榜。每一块各自标缺口；沪深 300 市盈率 / 股息率这次没有（官方文件是 xls，手机端暂无解析），页面如实写明。
- **交易日志 · 风险与纪律**：权益曲线与回撤、近 10 / 20 / 50 笔对比终身、纪律归因（按计划 / 计划外）、规矩逐条检查（会写明哪条没查及原因）、在险资金、按打法 / 是否按计划 / 持有周期分组；可设置费率、风险规矩、账户规模（默认值只是初值，不是推荐值）。只有清仓的交易计入已实现盈亏。个人成交、持仓和金额只在本机，不进任何 AI。

数据与存储：本地数据库升级到 v6，备份格式升到 v6（只新增交易日志设置，旧备份仍可恢复，恢复后设置回到默认）。行业资金用新浪口径，和东财「主力净额」不是一个口径；昨日成交额前十由 App 在收盘后记下，没开过盯盘的那天没有这份名单。

同时修复了长文本（如龙虎榜上榜理由）可能把整页撑宽的样式问题。

APK 为 debug-signed ARM64 预览版。正式签名 / AAB、真机生命周期及覆盖升级仍需验收，更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
