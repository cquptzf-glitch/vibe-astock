# Android 0.1.27 预览版

- **图片 / 文件分享**(Android 原生分享面板):
  - **图片复盘分享卡**:「复盘 → 今日情绪」页底部,生成当天情绪读数的图片(涨停、炸板、跌停、最高板、炸板率、昨日涨停股今日表现、整体晋级率),先看预览再分享;只放市场读数,不含自选、持仓、成本、盈亏,不放判断和买卖建议。
  - **报告文件分享**:「我的」里的研报、研究记录、收件箱每条多了「分享」按钮,按 Markdown 文件(.md)交给系统分享面板。
  - 分享的文件先写到应用缓存目录,通过 FileProvider 给分享面板一个只读地址,超过一天的缓存下次分享时清掉。这是原生功能,**这版没有在真机上验证过**,分享面板里能不能选到目标 App 取决于你的手机。
- **研报文件导入(先预览)**:「我的研报」页新增「从文件导入研报」:选文本文件(.txt / .md / .csv / .json,UTF-8 或 GBK,≤ 2 MB)→ 预览标题、字符数和开头 800 字(保存的是全文)→ 可改标题、分类、股票代码 → 保存。PDF、Word、Excel 手机端不解析正文,请先复制出文字或导出成文本。文件只在本机读取。
- **AI 复盘自动归档**:AI 交易复盘跑完后,自动存一份笔记到「研究记录」(分类「AI 复盘」,标题带日期,正文末尾写明模型、发送范围和时间),可以在「发送范围」里关掉这个开关;笔记在本机,可以改、可以删。

APK 为 debug-signed ARM64 预览版。真机验收、正式签名 / AAB 仍未完成,更换安装前请导出业务备份。剩余范围见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
