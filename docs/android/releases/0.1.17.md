# Android 0.1.17 预览版

本版优先解决移动端信息密度、设置入口与白色模式：

- 顶部固定显示“设置”和主题切换；设置页直接提供主题、密度、刷新频率、模型配置、通知与备份入口。
- 支持白色、深色、跟随系统；切换立即生效并保存，下次启动恢复。模型配置可在设置页直接展开。
- 默认紧凑布局，也可选舒适布局；统一 23 份业务样式的主题颜色，覆盖行情、持仓、日志、AI、发现及设置。
- 首页提供 6 个指数、沪深北成交额、市场宽度、涨跌分布、短线情绪、8 个功能入口和自选行情。自选行直接显示价格、涨跌幅、成交额和日期。
- 前台行情刷新可选 30/60/120 秒或仅手动，切到后台暂停；市场概览并发取数，缺少交易所数据时保留缺值。
- CI 增加 360/390/768 像素、明暗主题的浏览器操作与截图验证，检查主题保存、系统跟随、布局密度、设置入口及横向溢出。截图使用冻结测试数据，不能作为实时行情。

APK 为 debug-signed ARM64 预览版。正式签名/AAB、设备生命周期和覆盖升级仍未验收，更换安装前请导出业务备份。

本版没有宣称剩余业务全部移植完成。Kalshi 远期、完整盘中扫描、历史估值、AI 流式/多会话/工具/深研、完整回测、候选/日历及交易内容库深化、图片/文件分享、加密备份、持续后台盯盘、统一缓存离线等仍见 [ANDROID_REMAINING.md](https://github.com/cquptzf-glitch/vibe-astock/blob/android-mvp/ANDROID_REMAINING.md)。
