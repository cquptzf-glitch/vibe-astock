# 0.1.49 手机布局验收范围

本轮依据当前源码和 0.1.48 截图评估后实施，针对 Android/WebView 的实际组件安排功能。Apple HIG 是设计指导；下面的栏目划分、默认快捷入口和缓存上限为本项目的实现选择。

## 指南与实现

| 原则 | 本版实现 | 验收方式 |
| --- | --- | --- |
| 主要区域清晰、切换后保留导航状态 | 五项底栏；各栏目记忆最近工作页面；股票沿用来源栏目；恢复父级返回链 | 路由单元测试；跨栏目后返回股票/列表的浏览器交互 |
| 用层级列表承载较多功能 | 复盘三个功能分组；研究资料归入研究；我的四个直接设置入口；原有深链保留 | 所有登记入口唯一分组、路由双向解析；实际列表导航 |
| 分段选择用于紧密相关的视图 | 盯盘三个视图；取消复盘/研究的双排导航；保留个股三分区 | 渲染断言与实际页面检查 |
| 内容优先、命令靠近作用对象 | 首页先显示市场摘要；细分数据展开查看；通用命令收进页头菜单；图表导出仍在图表卡 | 首页顺序、菜单、真实 PNG 与原生分享载荷检查 |
| 字体可放大、操作可达 | 100%–200% 字号；相对单位；大字号时工具栏和标签换行；键盘编辑让位 | 四尺寸明暗主题；320px 明暗主题全部页面 200% 字号；模拟键盘视口 |
| 可预测的焦点与反馈 | 面板焦点约束、Escape、恢复触发控件；尊重减弱动态效果；报价保留正负号与日期说明 | 菜单/分享/自绘下拉交互；浏览器错误和触控尺寸检查 |

指南原文：

- [Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)：区域导航、保持区域状态、图标与文字标签。
- [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：按重要程度安排内容、表达层级、尊重安全区。
- [Segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls)：紧密相关的选择、清晰选中状态、限制选项数量。
- [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：文字放大、对比度、足够大的控件与替代交互。当前指南的 iOS 默认控件尺寸为 44×44pt；本项目 WebView 的 CSS 尺寸仍需设备上的实际显示比例验收。

## 自动化范围

- 全量前端测试、类型检查和桌面/独立移动构建。
- 路由测试覆盖栏目恢复、来源栏目、父级返回、冷启动深链、目录不覆盖栏目记忆。
- 浏览器采用公开冻结和合成夹具；四尺寸 320/360/390/768 × 明暗主题，逐路由和重点展开状态检查页面根部宽度、触控尺寸、测试接口覆盖和脚本错误。
- 栏目交互检查：可编辑快捷入口保存、资料筛选和滚动位置恢复、个股组件/选中视图恢复、来源列表返回、隐藏异动页面停止轮询、目录重入范围、菜单与分享面板、200% 字号、模拟键盘显示/恢复。
- 全部 48 个路由在 320px 明暗主题下检查 200% 字号，保留宽表的局部滚动，不以整体裁切掩盖根部溢出。
- K 线、分时、回测和月营收图表的真实 PNG 导出、资料边界、切换失效及原生分享字节一致性继续回归。

## 边界

上述浏览器模拟不是真机验收，不证明 Android 系统键盘、物理返回、字体比例、通知、Doze 或实际安装升级已通过。缓存只保留会话内状态，静态页面数量受路由集合限制，股票/板块详情最多六个；系统结束进程后未保存的输入可能丢失。所有历史数据、源站和旧研究工作流等价缺口继续参照 ANDROID_REMAINING.md，不因本轮布局优化而消除。
